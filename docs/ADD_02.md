# 追加機能仕様書 ADD_02 — 地図の全画面表示

| 項目 | 内容 |
|---|---|
| 文書番号 | ADD_02（RDD_06 への追加。フェーズ2 の V-6「本地図」を拡張） |
| 作成日 | 2026-09-08 |
| 状態 | 仕様案（実装前。利用者の確認待ち） |
| 対象画面 | 「地図と風向」 |

---

## 1. 目的

「地図と風向」は本文幅（スマホで約 340 px、高さ 260 px 前後）に収まる大きさで表示している。走行中や出走前の確認では、コース全体と風矢印をより大きく見たい場面がある。ボタン 1 つで地図を画面いっぱいに広げ、もう 1 つの操作で元に戻せるようにする。

## 2. 実現可能性の調査結果

| 項目 | 結果 |
|---|---|
| iPhone Safari（第一対象） | ブラウザ標準の全画面 API（`requestFullscreen`）は **動画以外の要素では使えない**。したがって「ページ内の要素を画面いっぱいに固定表示する」擬似全画面で実現する。ホーム画面に追加した PWA ではもともとブラウザの枠が無いので、擬似全画面でも端末の画面全体を使える。Safari で開いている場合はアドレスバーが残る（下部ツールバーは iOS 15 以降のレイアウトで表示範囲が可変なため、`100dvh` で実表示域に合わせる） |
| Android Chrome | 全画面 API が使える。擬似全画面に加えて `requestFullscreen` を呼ぶと、ステータスバーとブラウザ枠も隠れる |
| PC ブラウザ | 全画面 API が使える（Chrome / Safari / Edge）。Esc で解除される |
| Leaflet | 地図の入れ物の大きさを変えたあと `invalidateSize()` を呼べば、同じ地図インスタンスのまま拡大できる。再生成は不要で、表示中のズーム・位置・風矢印・ポップアップの状態を保てる |
| 静的地図（Leaflet が読めない場合） | SVG なので入れ物に合わせて拡大できる。入れ物の幅で描き直す既存処理を、全画面化の直後にも呼ぶ |
| 追加ライブラリ | 不要（CSS と既存の Leaflet だけで実現） |
| 画面の向き | 横向きの固定（`screen.orientation.lock`）は iPhone では使えず、Android でも全画面 API 中のみ有効。**固定はしない**。端末を回したときは表示域の変化に追従する |

結論：**実現可能**。iPhone では擬似全画面、対応環境では加えてブラウザ標準の全画面を使う 2 段構えにする。

## 3. ユーザーから見た動作

1. 「地図と風向」パネルの右上（「地図を画像で共有」の隣）に **「全画面」** ボタンを置く。
2. タップすると地図が画面いっぱいに広がる。表示中のズーム・位置は維持され、風矢印・進行方向記号・スタート／ゴール・現在地・線の色分けはそのまま。
3. 全画面中は次だけを地図に重ねて表示する。
   - 右上：**「閉じる ×」**（44 pt 以上）
   - 左上：Leaflet のズーム（＋／−）
   - 右下：**「全体」**（コース全体が収まる範囲に戻す）。走行中の再計算で現在地があるときは **「現在地」**（現在地を中心に拡大）も出す
   - 下端：線の色と矢印の凡例（1 行、半透明の帯）。出典表記（© OpenStreetMap contributors、Leaflet）は Leaflet 標準のまま残す
4. 「閉じる ×」、Esc（PC）、Android の戻る操作のいずれかで元の表示に戻る。戻ったあとも地図の位置・ズームは全画面中のものを引き継ぐ。
5. 全画面中は背面のページがスクロールしない。地図のドラッグ・ピンチ操作だけが効く。

## 4. 機能要件

### 4.1 表示の切り替え

| ID | 要件 |
|---|---|
| R-1 | 「地図と風向」パネルに「全画面」ボタンを置く。高さ 44 pt 以上。地図が未表示（コース未読み込み）のときは表示しない |
| R-2 | 擬似全画面：地図の入れ物に `position: fixed; inset: 0` を当て、高さは `100dvh`（未対応なら `100vh`）とし、`z-index` は他のすべてより上にする。上下左右の安全領域（`env(safe-area-inset-*)`）ぶん、閉じるボタンと凡例を内側に寄せる |
| R-3 | 全画面 API が使える環境（`document.fullscreenEnabled` が真）では、R-2 に加えて地図の入れ物に `requestFullscreen()` を要求する。拒否・失敗しても R-2 の表示で継続する |
| R-4 | 切り替え直後に Leaflet の `invalidateSize()` を呼ぶ。静的地図の場合は入れ物の幅で描き直す |
| R-5 | 全画面中は `html`／`body` のスクロールを止める（`overflow: hidden`）。閉じたら元に戻し、開く前のスクロール位置に戻す |
| R-6 | 閉じる操作：「閉じる ×」ボタン、Esc キー、全画面 API からの離脱（`fullscreenchange`）、ブラウザの戻る操作（開くときに `history.pushState`、`popstate` で閉じる）。どれで閉じても状態が揃うように 1 つの関数にまとめる |
| R-7 | 端末の回転・ウィンドウの大きさ変更に追従して `invalidateSize()` を呼ぶ（既存のリサイズ処理を全画面中も使う） |
| R-8 | 閉じたあとの地図は、全画面中の位置・ズームを引き継ぐ。再生成しない |

### 4.2 全画面中の操作

| ID | 要件 |
|---|---|
| R-9 | 「全体」ボタン：コース全体が収まる範囲に戻す（`fitBounds`、余白 16 px） |
| R-10 | 「現在地」ボタン：走行中の再計算で現在地があるときだけ表示し、現在地を中心にズーム 13 程度で表示する |
| R-11 | PC ではマウスホイールでのズームを全画面中だけ有効にする（通常表示ではページのスクロールを妨げないよう無効のまま） |
| R-12 | 風矢印の間引き（30 px 以上の間隔）と進行方向記号（90 px 間隔）は、全画面の大きさに合わせて既存の再配置処理で自動的に増える |
| R-13 | 風矢印のタップで出る詳細ポップアップは全画面中も同じ内容で出す |

### 4.3 表示要素

| ID | 要件 |
|---|---|
| R-14 | 凡例は 1 行に収める：線の色（雨・曇り・晴れ・予報範囲外）、矢印の色（向かい風・横風・追い風）、»＝進行方向。半透明の帯（背景色はテーマに従う） |
| R-15 | 「閉じる ×」は右上、44 pt 四方以上、白縁取りの丸ボタン。ダークモードでは配色を反転 |
| R-16 | 出典表記（Leaflet 標準の右下）は隠さない。凡例と重ならないよう、凡例は出典表記の上に置く |
| R-17 | 「地図を画像で共有」は全画面中には出さない（通常表示に戻ってから使う） |

## 5. エラーと表示文言

| 状況 | 動作 |
|---|---|
| 全画面 API が拒否された（ユーザー操作外での呼び出しなど） | 何も表示せず擬似全画面で継続 |
| Leaflet が読めていない（静的地図） | 静的地図を全画面で描き直す。ズーム・「全体」「現在地」ボタンは出さない |
| コース未読み込み | ボタン自体を出さない |

## 6. 非機能要件

- 切り替えは 1 秒以内。地図の再生成を行わない。
- 追加ライブラリなし。CSS と既存コードの範囲で実装する。
- 通常表示の地図の見た目・操作は変えない（回帰なし）。
- iPhone Safari 通常表示・ホーム画面追加の両方で確認する。Android Chrome と PC は動作すればよい。

## 7. 実装メモ

- 入れ物 `#mapWrap` に `fullscreen` クラスを付け外しする方式にし、Leaflet の DOM は動かさない（`L.map` のインスタンスを保つ）。クラス付与 → `requestAnimationFrame` の次で `lmap.invalidateSize()`。
- 高さは `height: 100dvh` を基本に、`@supports not (height: 100dvh)` で `100vh` にフォールバックする。
- スクロール停止は `document.documentElement.classList.add('noScroll')`（`overflow: hidden; height: 100%`）で行い、iOS の慣性スクロール抜けを防ぐため `body` にも同じ指定を入れる。
- 戻る操作：開くときに `history.pushState({ mapFull: true }, '')`、`popstate` で閉じる。閉じるボタン経由のときは `history.back()` を呼んで履歴を消費し、`popstate` 側で実際に閉じる（二重に閉じない）。
- 全画面 API は `el.requestFullscreen?.()` を `try/catch` で呼び、`document.addEventListener('fullscreenchange', …)` で離脱を検知する。iOS Safari では `requestFullscreen` が未定義なので自然に擬似全画面だけになる。
- 全画面中の `scrollWheelZoom` は `lmap.scrollWheelZoom.enable()` / `disable()` で切り替える。
- テストは §8 の受け入れ条件に対応させる。Node テストの対象は無い（画面だけの変更）。

## 8. 受け入れ条件

1. iPhone Safari（通常表示）で「全画面」を押すと、地図がアドレスバー以外の画面全体に広がり、「閉じる ×」で元に戻る。戻ったあとページのスクロール位置が保たれている
2. ホーム画面に追加した状態では、地図が端末の画面全体に広がる
3. 全画面中にピンチ・ドラッグ・ズームボタン・「全体」が使え、風矢印のタップで詳細が出る。矢印と進行方向記号の数が通常表示より増える
4. 端末を横向きにしても地図が表示域に追従する
5. Android Chrome で全画面（ステータスバー非表示）になり、戻る操作で元の表示に戻る
6. PC で Esc により元に戻る。マウスホイールのズームが全画面中だけ効く
7. 通常表示の地図の見た目・操作に変化がない
