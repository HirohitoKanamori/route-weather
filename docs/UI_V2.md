# UI_V2 — v2.0.0 の画面整理（2026-09-27）

v1.5.4 までに機能を足し続けて煩雑になった画面を、機能を減らさずに整理した記録。資料（計測・案・画面イメージ）は利用者と共有した artifact「Route-Weather.jp v2 UI 整理案」。

## 利用者の判断

| 項目 | 決定 |
|---|---|
| 色 | 案 A「森と生成り」。地 `#F3F5F0`、文字 `#102A1E`（ロゴ文字の深緑）、主ボタン `#11532C`。ダークは緑みの墨色 `#111713`。風・雨などの意味色は変えない |
| 注釈の置き場 | 別ページ `about.html`（このサイトについて）。画面の補足は ⓘ で開閉 |
| 試験運用中・Beta | v2.0.0 ですべて外す |
| 書体 | 端末の標準書体のまま |
| 要点 | ゴール予定は上段、文字の大きさの差は小さく（20 px 対 17 px）。指標は 向かい風・雨中・最高気温・最低気温・夜間 の 5 つ（最高気温を追加、最高を最低の前に） |

## 整理前の計測（v1.5.4、幅 390 px の結果画面）

- 表示文字 1,238 字のうち注釈・凡例・フッターが 714 字（58%）。段階 2 の後は 704 字中 190 字
- 枠線付きの角丸ブロック 21 個、文字サイズ 8 段階、全角括弧 17 か所

## 画面の構成（v2.0.0）

- ヘッダー：ロゴとメニュー（表示モード・現在位置から再取得・コース削除・このサイトについて）
- コース行（名前・距離・獲得標高・「変更」）と走行計画の札（出走・速度・仮眠・区間速度・編集）。札を押すと編集欄を開いてその項目へ
- コースの読み込み（ファイル・Ride with GPS 連携・URL・最近のコース・反転・サンプル）：未読み込みなら画面に、読み込み後は「変更」で開くシート（`#loadBox.open`、`.layout.hasCourse`）
- 要点：ゴール予定と 5 指標。指標をタップで地点・時刻・体感・小数までの距離（`#kpiDetail`）。共有画像の要点も同じ 6 項目（`summaryCards()` を共用）
- 「現在位置から予報を再取得」：出走 1 時間前〜ゴール 6 時間後、または現在地を使っているときだけ画面に。それ以外はメニューから（`renderGpsPlace()`）
- 凡例は色の札だけ。読み方は ⓘ の中
- フッター：出典と免責の 1 行、モデル初期時刻、このサイトについて、版

## 進め方の記録

別ブランチ `ui-v2` で 4 段階（色と文字 → 注釈の移設 → 構成の組み替え → Beta 終了と v2.0.0）に分け、段階ごとに幅 390 px のスクリーンショットで利用者の確認を得た。
